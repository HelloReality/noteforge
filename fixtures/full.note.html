Asymmetric crypto exchanges the session key; symmetric crypto encrypts the actual traffic — safe key distribution plus speed. Every session negotiates fresh keys, so stealing one private key cannot decrypt past recorded traffic. Never rely on a single control — layer them so one failure isn’t fatal. Encryption vs Hashing vs Encoding Encryption — reversible, needs a key Hashing — one-way, e.g. bcrypt for passwords Encoding — not a security control, e.g. Base64 Rule of thumb: encrypted → reversible with the key, and hashed → reversible somehow hashed → irreversible. Hybrid = asymmetric for the key, symmetric for the data. A user account looks compromised — what now?
