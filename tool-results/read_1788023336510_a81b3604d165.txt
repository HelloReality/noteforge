   449→  <section class="q-block">
   450→    <div class="q-head">
   451→      <span class="qnum">11.</span>Explain SQL Injection and how parameterized queries prevent it.
   452→    </div>
   453→    <ul class="notes">
   454→      <li>SQL Injection <span class="paren">(SQLi)</span> occurs when an attacker inserts <span class="ink-red">malicious SQL code</span> via input fields.</li>
   455→      <li>Attacker can read, modify or delete data, bypass authentication, escalate privileges, etc.</li>
   456→      <li><span class="ink-green">Prevention:</span> use parameterized queries / prepared statements, input validation, least-privilege DB accounts.</li>
   457→    </ul>
   458→
   459→    <div class="grid-2">

   464→          SELECT * FROM users<br>
   465→          WHERE username = '" + userInput + "'<br>
   466→          AND password = '" + pass + "'
   467→        </div>
   468→        <span class="label-small red">Attacker Input:</span>
   469→        <div class="code" style="color: var(--emphasis);">' OR '1'='1</div>
   470→        <span class="label-small red">Result:</span>
   471→        <div style="font-family: 'Architects Daughter', cursive; font-size: 14px; color: var(--emphasis);">
   472→          Condition always TRUE &rarr; <mark class="hl">Access Granted!</mark>

   474→      </div>

   482→          AND password = ?
   483→        </div>

   500→  <section class="q-block">
   501→    <div class="q-head">
   502→      <span class="qnum">12.</span>What is Cross-Site Scripting (XSS), and how is reflected XSS different from stored XSS?
   503→    </div>
   504→    <ul class="notes">
   505→      <li>XSS allows attackers to inject <span class="ink-red">malicious scripts</span> into web pages viewed by other users.</li>
   506→      <li><span class="ink-green">Reflected XSS:</span> payload is reflected off the server <span class="paren">(e.g. in search results, error messages)</span> &mdash; usually delivered via a crafted link.</li>
   507→      <li><span class="ink-red">Stored XSS:</span> payload is stored on the server <span class="paren">(e.g. in DB)</span> and served to every visitor &mdash; higher blast radius.</li>
   508→    </ul>

   613→      <span class="qnum">13.</span>What is CSRF, and how do CSRF tokens protect against it?
   614→    </div>
   615→    <ul class="notes">
   616→      <li>CSRF <span class="paren">(Cross-Site Request Forgery)</span> tricks a logged-in user into performing <span class="ink-red">unwanted actions</span> on a web app where they're authenticated.</li>

   618→      <li><span class="ink-green">CSRF Token</span> &mdash; a unique, unpredictable per-session value &mdash; ensures the request originated from the legitimate app UI.</li>

   698→    </div>
   699→    <ul class="notes">
   700→      <li>SSRF occurs when a server is tricked into making requests to <span class="ink-red">internal or external resources</span> on the attacker's behalf.</li>
